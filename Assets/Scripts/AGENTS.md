# 게임 코드 범위

이 폴더는 게임 진행 상태, 브라우저 저장, 열린 게임의 시간 흐름, 3D 섬 표현과 화면 조작을 담당한다. Editor 빌드 도구, 장면 파일, 프로젝트 설정은 이 폴더의 범위가 아니다.

- Game/State는 자원·집 단계·시간 계산의 유일한 변경 경계다. 자원은 음수가 될 수 없고 집은 미건설·기초·골조·완성 순서로만 진행하며, 각 건설 단계는 충분한 네 자원을 한 번만 소비한다.
- Game/Storage는 상태 직렬화와 브라우저 로컬 저장소만 담당한다. 읽기 또는 쓰기 실패는 새 저장이 없는 경우와 구분되어 화면에 전달되어야 한다.
- Game/Runtime은 열린 게임에서 생산 주기마다 상태 동작을 호출한다. 화면이 없어도 자동 생산과 동기 저장이 시작되어야 한다.
- Game/Presentation은 상태를 읽고 공개 행동만 호출한다. 저장 데이터나 자원 필드를 직접 변경하면 안 된다.

상태·시간·저장 규칙을 바꾸면 정상 흐름과 거부 흐름의 EditMode 검사를 함께 추가한다.
