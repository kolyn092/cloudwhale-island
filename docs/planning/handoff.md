# 구름고래의 작은 섬: 실행 인계서

## 실행 형태와 확인 기준

- 빈 프로젝트에서 시작하므로 초기 설정은 구현 작업 전에 한 번 준비한다.
- 현재 버전은 PC용 싱글 플레이 정적 웹 게임이다. 계정·서버·실시간 통신·외부 AI 호출을 추가하지 않는다.
- 실행 전과 후에 코드 검사, 자동 테스트, 생산 빌드를 실행한다. 게임이 실행되면 새 게임부터 엔딩·장식·새로고침 후 이어하기까지 직접 확인한다.
- 일부 AI 생성 이미지 요소를 사용하고, 공개 화면에 사용 도구와 AI 생성 사용 사실을 짧게 남긴다.

## 반드시 지킬 제약

- 플레이어에게 전투, 패배, 자원 손실, 시간 제한에 따른 벌칙을 주지 않는다.
- 미니게임을 끝내지 못해도 기본 보상은 지급한다.
- 시설은 `집 → 정원 → 공방 → 별 관측소` 순서와 세 건설 단계를 지킨다.
- 별 관측소 엔딩 뒤에도 장식과 저장된 진행은 유지된다.
- 장식은 현재 버전에서 능력치, 생산량, 이야기 분기를 바꾸지 않는다.
- 현재 이야기 기능은 문장 조합만 사용한다. 실제 AI 호출이나 대화형 주민은 확장 범위다.
- 저장은 현재 브라우저에만 남는다는 사실과 초기화 기능을 분명하게 보여 준다.

## 이번 구현에 포함되지 않는 의도

사용자는 나중에 실시간 친구 초대, 계정·온라인 저장, 실제 AI 이야기·대화, 자유 배치, 숲·바다 섬 테마, 여행자 이동·탐험을 원한다. 이 기능들은 현재 구현하지 않는다. 다만 장식·이야기·저장 경계는 이 확장을 막지 않도록 분리한다.

## 프로젝트 기반 정보

> 실행 대상이 아닌 프로젝트 맥락 — 구현 시 참고하고, 이후 프로젝트 문서의 출발점으로 사용한다.

### 프로젝트 정체성

- 포트폴리오와 친구 공유를 목표로 하는 2주짜리 PC 브라우저 게임이다.
- 포근한 색감의 고정 3D 쿼터뷰 디오라마에서 고래 섬을 돌보는 방치·제작 경험을 제공한다.
- 작은 범위에 맞춰 현재는 한 명이 링크로 즐기는 완결된 게임으로 공개한다.

### 세계와 규칙

- 길 잃은 여행자는 잠든 하늘고래의 등에 내려앉아, 고래가 깨어날 때까지 섬을 돌본다.
- 자원을 모아 집, 정원, 공방, 별 관측소를 세 단계로 완성한다. 완성 순서는 고정이다.
- 섬은 전투·실패 없이 아름다워진다. 희귀 발견 미니게임도 긴장이나 손실 대신 작은 보너스와 관찰의 재미를 준다.
- 마지막 시설을 완성하면 고래가 새 하늘로 날아가지만, 이후에도 장식으로 섬을 계속 꾸민다.

### 기술 결정

- Unity LTS와 C#으로 만든 3D WebGL 게임을 사용한다. 고정 쿼터뷰 카메라, 단순 모델, 조명, 그림자, 클릭 조작을 구현하기 위한 선택이다.
- 상태와 저장을 분리하고, 현재는 브라우저 로컬 저장소만 사용한다. 저장 형식에는 버전을 두어 이후 온라인 저장으로 옮길 여지를 남긴다.
- 이야기는 하나의 교체 가능한 생성 경계를 통해 문장 조합으로 만든다. 이후 외부 AI 서비스가 이 경계를 대체할 수 있다.
- 정적 웹 배포를 사용한다. 비밀 키나 외부 AI 키는 현재 프로젝트에 넣지 않는다.
- Unity 테스트 도구로 진행 상태·저장·핵심 조작을 우선 검증하고, 화면 분위기와 전체 흐름은 WebGL 빌드의 브라우저 점검으로 확인한다.

### 이후 범위

- 친구와 동시에 섬을 꾸미는 실시간 협동
- 계정과 온라인 저장으로 기기 간 이어하기
- 실제 AI로 만드는 세계관 이야기와 주민 대화
- 원하는 장소에 시설·장식을 놓는 자유 배치
- 숲과 바다를 배경으로 한 추가 섬 테마
