# 게임 규칙

유목, 구름솜, 이슬, 별가루는 0 이상의 정수다. 열린 게임에서는 네 자원이 같은 생산 주기와 생산량으로 증가한다.

오프라인 생산은 최대 24시간만 계산한다. 지급 횟수는 경과 초를 생산 주기로 나눈 내림값이며, 불완전한 주기는 이월하지 않는다. 저장 시각이 현재보다 미래면 보상은 0이다.

집은 `미건설 → 기초 → 골조 → 완성` 순서로만 진행하며 이전 단계로 돌아가지 않는다. 기초·골조·완성의 비용은 같은 기본값인 네 자원 각각 5개다. 현재 단계의 다음 단계만 건설할 수 있고, 모두 충분하면 각각 5개를 한 번만 차감한 뒤 즉시 저장한다. 하나라도 부족하거나 이미 완성됐으면 자원·집 단계·저장은 그대로이며 이유를 알린다. 기존 기초 저장은 계속 유효하며 골조 건설로 이어진다.

공통 시설 목록에는 하나의 `garden`만 저장한다. 집이 완성되기 전 정원은 잠긴 빈터이며 건설할 수 없다. 집 완성 뒤 정원은 `잠김 → 기초 → 골조 → 완성` 순서로 진행한다. 각 단계는 네 자원 각각 5개를 한 번만 차감하고 즉시 저장한다. 재료 부족, 집 미완성, 완료된 정원의 재시도는 상태와 저장을 바꾸지 않고 이유를 알린다. 기존 저장에 시설 목록이 없거나 비어 있으면 잠긴 정원으로 복구하며, 알 수 없는 시설 ID, 중복 정원, 허용되지 않은 단계는 손상 저장으로 새 게임 상태로 복구한다.

정원 완료 전에는 네 자원이 60초마다 각각 1개씩 생산된다. 정원 완료 뒤에는 유목·별가루는 1개, 구름솜·이슬은 각각 2개씩 생산된다. 정원 기초·골조는 생산량을 바꾸지 않으며, 정원 완료 전의 생산 주기에 완료 보상을 소급 적용하지 않는다.

손상 저장, 음수 자원, 허용되지 않은 집 단계는 새 게임 상태로 복구하고 복구 사실을 알린다. 저장소 읽기·쓰기 실패는 열린 게임을 멈추지 않지만 이번 진행이 저장되지 않음을 알려야 한다.

전투, 패배, 경쟁, 시간 초과 벌칙, 자원 손실은 현재 규칙이 아니다.
