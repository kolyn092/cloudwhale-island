# 구름고래의 작은 섬: 첫 공개 버전 명세

## 목표와 동기

2주 안에 포트폴리오와 친구 공유용으로 공개할 PC 브라우저 게임을 만든다. 플레이어는 잠든 하늘고래의 등에 내려앉은 작은 여행자로서, 고래가 깨어날 때까지 섬을 돌본다. 실패·전투·경쟁 없이 방치, 제작, 건축, 꾸미기를 통해 섬이 아름다워지는 경험이 핵심이다.

## 범위

- PC 브라우저에서 실행되는 싱글 플레이 게임이다.
- 화면은 단순화한 3D 모델과 부드러운 색감으로 만든 고정 쿼터뷰 디오라마다.
- 로그인 없이 현재 브라우저에만 진행 상황을 저장한다.
- 완성본은 링크로 접근 가능한 무료 정적 웹사이트로 공개한다.

## 세계와 핵심 대상

- **여행자**: 길을 잃고 잠든 하늘고래의 등에 내려앉은 플레이어의 관찰자다. 직접 이동시키지 않는다.
- **하늘고래 섬**: 자원이 생기고 시설과 장식이 놓이는 하나의 고정된 쿼터뷰 장면이다.
- **기본 자원**: `유목`, `구름솜`, `이슬`, `별가루` 네 종류다. 수량은 음수가 될 수 없다.
- **제작물**: `별빛 부품`은 공방에서 별가루로 만드는 별 관측소 전용 재료다. 수량은 음수가 될 수 없다.
- **시설**: `집`, `정원`, `공방`, `별 관측소` 네 종류다. 각 시설은 `미건설 → 기초 → 골조 → 완성`의 세 건설 단계를 거친다.
- **이야기 기록**: 시설이 완성될 때 열리는 한 페이지 분량의 이야기다. 이미 열린 이야기는 기록첩에서 다시 볼 수 있다.
- **장식**: 나무, 꽃, 등불, 벤치처럼 엔딩 후 섬에 놓을 수 있는 순수 시각 요소다. 현재 버전에서는 생산량이나 이야기 분기에 영향을 주지 않는다.

## 플레이 규칙

1. 기본 자원은 시간이 지나는 동안 자동으로 쌓인다. 시작 자원, 생산 주기, 생산량, 시설별 재료 비용은 플레이 감각에 맞춰 조정 가능한 기본값으로 둔다.
2. 희귀 자원 발견 기회가 섬에 나타난다. 플레이어는 이를 눌러 짧은 미니게임을 시작한다.
3. 미니게임은 5초 안에 화면에 표시된 별 세 개를 정해진 순서로 누르는 단순 조작이다. 성공하면 별가루 보너스를 받고, 시간 안에 끝내지 못해도 기본 보상은 받는다. 실패·손실·벌칙은 없다.
4. 시설은 `집 → 정원 → 공방 → 별 관측소` 순으로만 건설할 수 있다. 다음 시설은 이전 시설이 완성된 뒤에만 건설할 수 있다.
5. 집·정원·공방의 건설 단계는 유목, 구름솜, 이슬, 별가루의 정해진 묶음을 직접 소비한다. 모든 소비는 필요한 자원이 있을 때만 수행한다. 각 단계의 수량은 조정 가능한 기본값으로 둔다.
6. 집은 생활의 시작을, 정원은 이슬과 구름솜 생산을, 공방은 별가루로 `별빛 부품`을 제작하는 기능을, 별 관측소는 마지막 이야기와 엔딩을 연다. 공방을 완성하기 전에는 별빛 부품을 만들 수 없고, 별 관측소의 세 건설 단계는 각각 별빛 부품 하나를 소비한다.
7. 시설의 각 단계가 시작되면 섬의 외형이 즉시 해당 단계 모습으로 바뀐다. 완료된 시설은 이전 단계로 내려가지 않는다.
8. 별 관측소를 완성하면 고래가 깨어나 새로운 하늘로 날아가는 엔딩을 한 번 보여 준다. 엔딩을 본 뒤에도 저장된 진행을 유지하며 장식을 계속 제작·배치할 수 있다.
9. 장식은 미리 정한 빈 장식 자리에서만 선택해 놓는다. 장식 종류를 추가하는 데이터와 화면 구성이 분리되어, 이후 장식 목록을 늘리기 쉽도록 만든다.
10. 현재 버전의 이야기는 외부 AI 호출 없이, 시설 완성·진행 상태에 맞춘 문장 조각을 조합해 만든다. 각 시설 완성 시 한 페이지를 자동으로 보여 주고 기록첩에 보관한다.

## 저장과 복구

- 기본 자원, 별빛 부품, 시설 단계, 엔딩 확인 여부, 놓인 장식, 열린 이야기 기록을 브라우저의 로컬 저장소에 저장한다.
- 의미 있는 행동(자원 획득, 건설 단계 변경, 미니게임 보상, 장식 배치, 엔딩 확인) 뒤에는 저장된 상태를 갱신한다.
- 새 방문자는 초기 상태에서 시작하고, 저장된 상태가 있으면 이어서 시작한다.
- 설정 화면은 저장 내용이 현재 브라우저에만 남는다는 사실과 초기화 기능을 제공한다. 초기화는 확인 후에만 실행한다.
- 저장소를 사용할 수 없으면 게임은 현재 열린 화면에서는 계속 동작하되, 저장되지 않는 이유를 알린다.
- 저장 데이터는 읽을 때 기본 자원과 별빛 부품 수량, 시설 단계, 잠금 순서, 장식 자리, 이야기 기록을 검사한다. 데이터가 깨졌거나 불가능한 상태이면 새 게임 상태로 되돌리고 이유를 알린다. 현재 버전은 로컬 저장 데이터의 수정을 막지 않는다.

## 화면과 조작

- 주 화면에는 고래 섬, 네 개의 고정 시설 자리, 현재 자원, 진행 가능한 행동, 희귀 자원 발견, 이야기·장식·설정 진입점이 보인다.
- 건설할 수 없는 시설과 단계는 필요한 조건 또는 부족한 재료를 명확히 알려 주며, 자원을 소비하지 않는다.
- 쿼터뷰는 고정된 3D 카메라로 유지한다. 시설, 나무, 구름, 장식에는 단순한 모델, 조명, 그림자를 사용해 입체감을 만든다.
- 부드러운 색감의 직접 제작한 단순 3D 요소를 기본으로 쓰고, 일부 AI 생성 이미지는 배경·장식용 질감 또는 안내 이미지로 사용한다. 공개 화면의 크레딧에는 AI 생성 요소의 사용 사실과 사용 도구를 짧게 표기한다.

## 범위 밖과 확장 방향

- 현재 버전에는 실시간 친구 초대, 계정, 온라인 저장, 실제 외부 AI 이야기 생성, 자유 배치, 숲·바다 테마, 플레이어 이동과 탐험은 넣지 않는다.
- 향후에는 실시간 협동, 계정 기반 이어하기, 실제 AI 주민 대화·이야기, 자유 배치, 다른 테마 섬으로 확장할 수 있어야 한다.

## 설계 근거

- 고정 3D 쿼터뷰와 직접 이동 없는 관리형 조작을 선택해, 2주 내에 포근한 디오라마 감성과 완성도 있는 제작 흐름을 함께 확보한다.
- 전투·실패를 없애고 미니게임 실패에도 기본 보상을 주어 치유형 방치 경험을 지킨다.
- 지금은 문장 조합으로 이야기를 만들지만, 이야기 생성 경계를 한 곳에 두어 나중에 실제 AI 서비스로 교체할 수 있게 한다.
- 정해진 빈터와 장식 데이터 분리를 사용해 첫 버전의 제작 비용을 제한하면서 자유 배치·장식 확장의 기반을 남긴다.

## 필요한 검증

- 자동 자원 축적, 자원 소비, 순차 해금, 세 단계 건설, 엔딩 조건, 장식 제한, 이야기 기록, 저장·불러오기·초기화를 자동 테스트한다.
- PC 브라우저에서 새 게임부터 네 시설 완성, 엔딩 확인, 장식 배치, 새로고침 후 이어하기까지 수동으로 점검한다.
- 생산 빌드와 코드 검사 및 테스트 명령이 모두 성공해야 한다.
