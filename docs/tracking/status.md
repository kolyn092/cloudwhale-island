# 현재 상태

현재 구현은 PC Web용 고정 3D 쿼터뷰 섬, 네 자원의 자동 생산, 최대 24시간 오프라인 반영, 집의 기초·골조·완성 건설, 브라우저 로컬 저장·복구, Web 생산 빌드까지 포함한다. Unity Editor와 Development Build에서는 다음 자원 생산까지 남은 시간을 표시한다.

다음 범위는 정원, 공방, 별 관측소, 별빛 부품, 희귀 발견, 미니게임, 이야기, 엔딩, 장식, 저장 초기화다.

GitHub Pages 실제 공개, 계정 저장, 협동, 자유 배치, 외부 AI 이야기, 추가 섬 테마, 여행자 이동은 아직 구현되지 않았다.
