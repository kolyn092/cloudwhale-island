# 현재 상태

현재 구현은 PC Web용 3D 쿼터뷰 섬과 드래그 회전 카메라, 네 자원의 자동 생산, 최대 24시간 오프라인 반영, 집의 기초·골조·완성 건설, 집 완료 뒤 정원의 잠김·기초·골조·완성 건설, 브라우저 로컬 저장·복구, Web 생산 빌드까지 포함한다. 정원 완료 뒤 구름솜·이슬 생산량은 60초마다 각각 2개이며, 유목·별가루는 각각 1개를 유지한다. Unity Editor와 Development Build에서는 다음 자원 생산까지 남은 시간을 표시한다. 카메라 회전과 입력 경계 검사를 포함해 EditMode 자동 검사 62개가 통과했다.

다음 범위는 공방, 별 관측소, 별빛 부품, 희귀 발견, 미니게임, 이야기, 엔딩, 장식, 저장 초기화다.

2026-09-05 드래그 회전 추가 뒤 Web 생산 빌드가 성공했다. 로컬 브라우저에서 좌우·상하 드래그로 집 뒤 정원 골조가 드러나며, 정보 패널 드래그는 시점을 바꾸지 않는 것을 직접 확인했다.

GitHub Pages 실제 공개, 계정 저장, 협동, 자유 배치, 외부 AI 이야기, 추가 섬 테마, 여행자 이동은 아직 구현되지 않았다.
