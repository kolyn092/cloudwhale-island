# 해결되지 않은 문제

현재 자동 검사와 Web 생산 빌드에서 재현된 미해결 문제는 없다.

## 해결한 표현 문제

- 고래의 흰 분수 구름이 지면에 박혀 보였다. 섬 외곽 밖의 고래 머리 위로 옮겨 지면·몸통과 분리했다.

- 부모 크기를 먼저 바꾼 뒤 `SetParent(..., true)`로 부품을 묶어 집·지형 크기 조정이 상쇄되었다. 집·정원은 부품을 묶은 다음 지면 기준점 주위로 50% 축소하도록 수정했다. 이전 지형 확대 수치는 실제 화면에 반영되지 않았으므로 제거했다.
- 정원이 섬 외곽을 벗어났다. 정원 중심을 안쪽으로 옮기고 전체 크기를 절반으로 줄였다. 고래 몸통의 수평 중심도 땅 중심과 맞췄다.
