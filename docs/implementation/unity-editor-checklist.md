# Unity Editor 확인 목록

## 처음 한 번

1. Unity Hub에서 이 폴더를 Unity 6000.3.23f1로 연다.
2. Build Profiles에서 `Web` 프로필을 추가한다. Hub의 설치 모듈 표기는 `Web Build Support`일 수 있다.
3. 기본 장면을 열어 씬이 저장되는지 확인한다.

## 첫 구현 단위 확인

1. 게임 화면에서 고래 섬, 집 자리, 네 자원, 건설 행동, 저장 상태 안내가 보이는지 확인한다.
2. 자원이 자동으로 늘어나는지 확인한다.
3. 네 자원이 각각 5 이상일 때 `Build next house stage`를 눌러 미건설 → 기초가 되고, 기초 바닥 외형으로 즉시 바뀌는지 확인한다.
4. 다시 네 자원을 각각 5개 이상 모아 기초 → 골조로 진행한 뒤, 기둥과 들보만 있는 골조 외형으로 즉시 바뀌는지 확인한다.
5. 다시 네 자원을 각각 5개 이상 모아 골조 → 완성으로 진행한 뒤, 벽·지붕·문이 있는 완성 집 외형으로 즉시 바뀌고 건설 행동이 사라지는지 확인한다.
6. 각 미완성 단계에서 부족한 재료로 건설을 시도했을 때 자원과 집 단계가 변하지 않고 안내가 보이는지 확인한다.
7. 실행을 멈춘 뒤 다시 열어 저장 복구와 오프라인 보상을 확인한다.

## 정원 구현 단위 확인

모든 정원 단계에서 흙 바닥이 사각형이고 네 모서리가 땅 안에 들어가는지 확인한다. 완성 정원은 분홍·노랑·보라 꽃 여섯 송이로 표현된다. 집·정원은 모든 단계에서 원래 부품 크기의 50%, 나무는 기존 크기의 50%이며, 발밑이 지면에 연결되어야 한다. 고래 몸통과 땅의 수평 중심이 일치하고 등이 흙 아래에 연결되는지 정면·측면·후면으로 회전해 확인한다.

1. 집이 미완성인 새 게임에서 집 외형과 함께 `Garden: Locked vacant lot` 및 잠긴 빈터·표지판 외형이 보이고, 집을 먼저 완성하라는 안내와 정원 건설 행동이 숨겨지는지 확인한다.
2. 집을 기초·골조·완성까지 진행해도 현재 집 외형이 유지되는지 확인한다. 집 완성 직후 정원 기초 건설 행동과 유목·구름솜·이슬·별가루 각각 5개 비용이 보이는지 확인한다.
3. 집 완료 뒤 정원 재료가 부족한 상태에서 정원 건설을 시도했을 때 자원·정원 단계가 변하지 않고 부족 안내가 보이는지 확인한다.
4. 네 자원이 각각 5 이상일 때마다 `Build next garden stage`를 눌러 잠긴 빈터 → 흙 화단 기초 → 기둥·들보 골조 → 꽃이 핀 완성 정원 외형으로 즉시 바뀌는지 확인한다. 집의 완성 외형도 계속 함께 보여야 한다.
5. 정원 완료 뒤 정원 건설 행동이 숨겨지고 완료 안내가 보이는지 확인한다. Unity Editor 개발 안내에 다음 생산 주기와 `Driftwood +1 · Cloud Cotton +2 · Dew +2 · Stardust +1`이 표시되는지 확인한다.

## Web 빌드 확인

완성 집을 낮은 시점에서 앞·뒤·옆으로 돌려 보며 벽 아래 기단이 지면과 이어지고, 집과 지면 사이로 배경이 비치지 않는지 확인한다.

같은 낮은 시점에서 기울어진 지붕의 높은 쪽 끝도 벽 윗면과 이어지고, 벽과 지붕 사이로 하늘이 비치지 않는지 확인한다.

게임 화면의 정보 패널 밖에서 왼쪽 마우스 버튼을 누르고 좌우로 드래그해 섬의 뒷면과 정원이 드러나는지 확인한다. 위아래로 드래그하면 내려다보는 각도가 바뀌며 섬 밑으로 뒤집히지 않아야 한다. 건설 버튼과 정보 패널에서 시작한 드래그는 카메라를 움직이지 않아야 하며, 버튼을 놓거나 창을 벗어나면 회전이 멈춰야 한다. 새로고침하면 처음 시점으로 돌아온다.

1. `Builds/Web/index.html`이 생성된 뒤, Web 서버로 `Builds/Web` 폴더를 연다. `file://` 주소로 직접 열면 브라우저 보안 정책 때문에 정상 실행을 보장할 수 없다.
2. 새 게임에서 자원이 늘어나는지 확인한다.
3. 네 자원이 각각 5 이상이 될 때마다 `Build next house stage`를 눌러 기초, 골조, 완성 집 외형이 순서대로 바뀌는지 확인한다. 매번 자원이 각각 5만큼 줄고, 완성 뒤에는 건설 행동이 보이지 않아야 한다.
4. 새로고침 뒤 집 단계와 자원이 복구되는지 확인한다. 짧게 페이지를 닫았다가 다시 열었을 때는 완전히 지난 생산 주기만 보상되는지 확인한다.
5. 집을 완성한 뒤 네 자원이 각각 5 이상일 때마다 `Build next garden stage`를 세 번 눌러 정원 기초·골조·완성 외형과 완료 안내를 확인한다. 완료 뒤 다음 생산 주기에 유목·별가루는 1개, 구름솜·이슬은 각각 2개 늘어나는지 확인한다.
