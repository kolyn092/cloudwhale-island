# 구성

Unity 6000.3.23f1 프로젝트는 하나의 시작 장면에서 실행된다. 시작 시 게임 런타임이 브라우저 저장소에서 진행 상태를 읽고 시간 경과분을 계산한 뒤 생산 루프와 섬 표현을 생성한다.

상태 계층은 자원·시설 단계·저장 시각을 소유한다. 저장 계층은 이를 문자열로 직렬화해 Web 로컬 저장소에 동기 기록한다. 표현 계층은 상태를 읽어 3D 고래 섬과 화면을 만들고 건설 요청만 상태 계층으로 보낸다.

외부 서비스는 없다. Web 빌드는 정적 파일이며 브라우저 로컬 저장소 외에 네트워크 의존성이 없다.

카메라는 섬 중심을 바라보며 화면 드래그로 회전한다. 좌우로 360도 회전하고 내려다보는 각도는 15~65도로 제한한다. 회전은 표현 계층에만 남으며 진행 저장에는 포함하지 않는다. 정보 패널 위에서 시작한 입력은 건설 화면이 처리한다.
